# GitHub Milestones

This document defines the milestones used for organizing work phases.

## Phase 1: Repository Foundation (M1)

**Goal:** Set up GitHub processes, documentation, templates, and CI/CD

**Issues:**
- Repository initialization
- Documentation (README, CONTRIBUTING, WORKFLOW, AI_AGENT_GUIDE)
- GitHub templates and automation
- CI/CD pipeline setup
- Team workflow documentation

**Duration:** Week 1  
**Status:** In Progress

---

## Phase 2: Dataset Registry Module (M2)

**Goal:** Implement first learning module with full-stack functionality

**Issues:**
- Backend dataset CRUD endpoints
- Frontend dataset management UI
- Tests and coverage
- API documentation
- Integration testing

**Dependencies:** Requires M1 completion  
**Duration:** Week 2-3  
**Status:** Planned

---

## Phase 3: Pipeline Simulation (M3)

**Goal:** Add advanced features simulating real data platform components

**Issues:**

- Dataset preview functionality
- Status tracking
- Advanced queries
- System integration

**Dependencies:** Requires M2 completion  
**Duration:** Week 4+  
**Status:** Planned
